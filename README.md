# Radical Lab

Переносимый офлайн-калькулятор комплексных чисел и символьных выражений. Учебный проект по программной инженерии: от `std::sqrt(x)` к приложению с контрактом, интерфейсом, проверками, выпуском и планом сопровождения.

**[Открыть приложение](https://kotyasmol.github.io/radical-lab/) · [Скачать офлайн-версию](https://github.com/kotyasmol/radical-lab/releases/latest/download/radical-lab.html) · [Документация](docs/README.md)**

## Запуск без установки

1. Скачайте `radical-lab.html` из [Releases](https://github.com/kotyasmol/radical-lab/releases).
2. Откройте файл в современном настольном браузере. Можно скопировать его на флешку: все библиотеки уже внутри, интернет для вычислений не нужен.
3. Введите выражение, выберите точность и нажмите «Вычислить» или Enter.

Веб-версия требует сети при загрузке. Переносимый HTML работает через `file://` без локального сервера. Интерфейс: русский, английский, испанский, упрощённый китайский. Язык выбирается автоматически и меняется вручную.

## Возможности

- Действительные и комплексные числа: обе компоненты используют десятичную длинную арифметику decimal.js, а не `Number`/`double`.
- 2–200 значащих цифр вычислений; отдельно настраивается количество цифр вывода и научный формат.
- `+ - * / ^`, скобки, `pi`, `e`, `i`, `sqrt`, `sin`, `cos`, `tan`, `exp`, `ln`/`log`, `abs`, `re`, `im`, `conj`.
- Символьное упрощение Nerdamer: переменные `x`, `y`, `z`, дроби, радикалы, тождества.
- Читаемые ошибки, отмена и принудительный тайм-аут вычислителя через 4 секунды.
- История последних 50 расчётов только в памяти, экспорт JSON, кнопка очистки сеанса.
- Никаких аккаунтов, телеметрии, CDN, сервера вычислений, cookies, localStorage или service worker.
- Проверка обновлений только по кнопке; обновление заменой HTML, откат старым файлом.

| Выражение    | Режим              | Результат               |
| ------------ | ------------------ | ----------------------- |
| `sqrt(-1)`   | Численно           | `i`                     |
| `(2+3*i)^2`  | Численно           | `-5 + 12i`              |
| `0.1+0.2`    | Численно           | `0.3`                   |
| `sqrt(0,25)` | Численно           | `0.5`                   |
| `sqrt(2)`    | Численно, вывод 20 | `1.4142135623730950488` |
| `sqrt(8)`    | Символьно          | `2*sqrt(2)`             |
| `x+x`        | Символьно          | `2*x`                   |
| `1/3`        | Символьно          | `1/3`                   |

Это ограниченный калькулятор, а не универсальная CAS: он не решает уравнения, не дифференцирует и не строит графики. Численные результаты приближённые; выбранное число цифр не является доказанной границей погрешности. [Контракт и ограничения](docs/REQUIREMENTS.md).

## Разработка

Нужны Node.js **22.12+ (ветка 22 LTS)** и npm. Интернет нужен для первой установки зависимостей и браузеров. Используйте закреплённый lock-файл.

```sh
npm ci
npm run dev
```

```sh
npm run test:coverage
npm run build
npx playwright install --with-deps chromium firefox webkit
npm run test:e2e
```

`npm run build` создаёт `dist/radical-lab.html`, `dist/index.html`, `dist/SHA256SUMS.txt` и `dist/version.json`. `npm run check` выполняет полную локальную проверку. `npm run test:e2e -- --project=chromium` — один браузер.

В пользовательском дистрибутиве **Node.js не нужен**. Подробные инструкции для Windows, macOS и Linux: [INSTALL.md](docs/INSTALL.md).

## Почему один файл?

Возможный ответ на «экстравагантный способ сократить сопровождение» — **сократить число обслуживаемых частей и зафиксировать законченный продукт**. Здесь отсутствуют бэкенд, база, учётные записи, установщик и платформенные пакеты. HTML — версионируемый переносимый артефакт, вычисления локальны. Это уменьшает затраты, но не обещает десять лет работы без проверки совместимости и исправлений. Альтернативную трактовку преподавателя нужно уточнить.

## Удаление

Нажмите «Завершить сеанс», закройте все вкладки приложения и удалите HTML. Экспортированные JSON-файлы удаляются отдельно. Приложение не устанавливает службы и ничего не пишет в реестр. Кэши браузера, история скачиваний, резервные копии и синхронизация не находятся под его контролем: абсолютное «100% стирание всех следов» технически не обещается. [Полная процедура](docs/INSTALL.md#удаление).
