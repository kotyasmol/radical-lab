# Дизайн интерфейса

## Принцип

Рабочая поверхность научного блокнота: выражение и результат в центре внимания, точность в правой панели, примеры и история ниже. Без маркетинговой страницы, картинок-заглушек, внешних шрифтов или повторяющихся декоративных карточек.

Дизайн создан по полному визуальному концепту с помощью встроенной генерации изображений в рамках frontend-app-builder. [Исходный концепт](screenshots/concept.png), [реальный desktop](screenshots/desktop.png), [мобильный интерфейс](screenshots/mobile.png). Концепт не является интерфейсом: весь UI реализован доступными HTML-контролами.

Краткий бриф генерации: «Radical Lab; автономный научный калькулятор; белый фон, тёмный текст, глубокий бирюзовый акцент; поле выражения, численный/символьный режим, результат, примеры, история и панель точности; четыре языка, настольный и адаптивный сценарий». Генерация выполнена встроенным инструментом, не через отдельный платный API-ключ.

| Радиус | 6–8 px, диалог 12 px |

| Заголовки | 32–44 px H1, 19–24 px H2 |

Отсутствие CDN/шрифтовых запросов поддерживает офлайн-запуск. Различия системных шрифтов между ОС принимаются; размеры и переносы проверяются отдельно.

## Состояния и доступность

Пустой результат, вычисление, успешный ответ, предупреждение, ошибка, отмена, история/пустая история, справка, очистка с подтверждением, обновление/сеть недоступна. Численный/символьный режим — кнопки с `aria-pressed`. Поля имеют labels, результат — live region, ошибки — alerts. Enter вычисляет; Shift+Enter переводит строку; IME-композиция китайского текста не вызывает ранний расчёт. Модальный `dialog` удерживает фокус, Escape закрывает.

Контраст проверяется axe; есть видимый focus и reduced-motion. Длинные результаты переносятся и не растягивают экран. Мобильный layout складывает панель точности под калькулятор. Изменение языка не стирает выражение и расчёт.

## Визуальная проверка и различия с концептом

Интерактивная проверка: встроенный браузер Codex, настоящий комплексный расчёт. Регрессионные скриншоты: Playwright Chromium, desktop viewport 1536×1024 (полная страница длиннее viewport из-за реальной истории), mobile 390×844. Концепт и оба изображения просмотрены непосредственно через инструмент просмотра изображений, а не только по DOM.

| Сравнение | Концепт → реализация | Решение |
| --- | --- | --- |
| Композиция | Шапка, крупный H1, две колонки, редактор→результат→примеры→история | Сохранена последовательность и приоритет |
| Палитра | Белый фон, тёмный текст, бирюзовый CTA и светлый результат | Сохранена; без новых градиентов/декора |
| Типографика | Sans для UI, mono для формул | Сохранена, системные семейства ради автономности |
| Контролы | Два режима, поля 50/20, формат, язык, справка | Рабочие, с labels и клавиатурой |
| Иконки | Небольшие контурные copy/export/delete/chevron | Локальные SVG одной толщины, без сети |
| Содержание | «Без ограничений» в концепте против фактических лимитов | Намеренно заменено на «под вашим контролем»; ложное обещание удалено |
| Подзаголовок | «Точные выражения» → «Символьные выражения» | Уточнена разница точного символа и численной погрешности |
| Подсказки | Общий текст точности → значащие цифры, ограничения и half-even | Намеренное уточнение контракта; добавлена полезная длина текста |
| История | В концепте пусто при показанном результате | Реальная история содержит рассчитанный пример; фиктивное состояние не воспроизводится |
| Плотность | Контентная ширина 1320, редактируемое многострочное поле | Намеренная адаптация для длинных формул/переводов, без переполнений |
| Mobile | Расширение desktop-системы в одну колонку | Проверены испанские длинные подписи и отсутствие горизонтального скролла |

Сверка первого экрана: обязательные пункты сохранены; изменения текста/плотности перечислены выше и связаны с точным пользовательским контрактом. Непреднамеренных обрезаний, неработающих основных контролов и незагруженных ресурсов при проверке не осталось. Реализация проверена на соответствие концепту с указанными намеренными отклонениями; пиксельное совпадение разных системных шрифтов не заявляется.
