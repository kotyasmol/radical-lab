# Запуск, установка, перенос и удаление

## Для пользователя

### Онлайн

Откройте [GitHub Pages](https://kotyasmol.github.io/radical-lab/). При загрузке нужен интернет; вычисления происходят локально. Для гарантированного последующего офлайн-запуска скачайте релизный файл — автоматическое кэширование веб-версии не обещается.

### Офлайн / portable

1. Откройте [последний релиз](https://github.com/kotyasmol/radical-lab/releases/latest).
2. Скачайте `radical-lab.html`. Не заменяйте его сохранением исходной страницы GitHub.
3. Сохраните файл, например в папку «Документы/Radical Lab».
4. Откройте через меню «Открыть с помощью» → Chrome, Edge, Firefox или Safari. Не используйте предпросмотр HTML файловым менеджером.
5. Проверьте `sqrt(-1)` → `i`. Отключите сеть и повторите.

Все нужные JavaScript/CSS и библиотеки в HTML. Установщик, Python, Node.js, администраторские права и сервер пользователю не нужны. Размер около 1.2 MB; точный размер зависит от сборки.

Для переноса скопируйте **только этот HTML** на другую поддерживаемую машину. Если нужна история, экспортируйте JSON отдельно. Автоматического импорта истории в v1.0 нет; JSON читается любым текстовым редактором.

### Проверка контрольной суммы

Рядом с HTML опубликован `SHA256SUMS.txt`. В Windows PowerShell:

```powershell
Get-FileHash .\radical-lab.html -Algorithm SHA256
```

В macOS:

```sh
shasum -a 256 radical-lab.html
```

В Linux:

```sh
sha256sum -c SHA256SUMS.txt
```

Сравните сумму с файлом из того же релиза. Контрольная сумма обнаруживает повреждение файла; сама по себе без доверенного канала она не доказывает подлинность автора. Источник релиза — HTTPS GitHub данного репозитория.

## Заявленная матрица поддержки

| Платформа | Целевой браузер | Способ запуска |
| --- | --- | --- |
| Windows 11 x64 | Chrome/Edge/Firefox: текущая и предыдущая стабильная версия | HTTPS или локальный HTML |
| macOS 14+ Intel/Apple Silicon | Safari текущей ОС, Chrome/Firefox текущий и предыдущий | HTTPS или локальный HTML |
| Ubuntu 22.04+ x64 | Chrome/Firefox текущий и предыдущий | HTTPS или локальный HTML |
| Android/iOS | Адаптивный веб-интерфейс — best effort | HTTPS; локальные файлы не являются обязательной конфигурацией |

Это целевая матрица, а не утверждение, что вручную проверена каждая комбинация. Реально выполненные проверки и ограничения приведены в [TESTING](TESTING.md). WebKit в Playwright не тождествен всем версиям Safari. Windows ARM, старые браузеры, встроенные просмотровщики и политики, запрещающие Worker/Blob, требуют отдельной квалификации.

## Разработчику

1. Установите Node.js 22 LTS (22.12+), npm и Git.
2. `git clone https://github.com/kotyasmol/radical-lab.git`, затем `cd radical-lab`.
3. `npm ci` устанавливает точные версии из `package-lock.json`.
4. `npm run dev` печатает адрес локального dev-сервера.
5. `npm run build` создаёт готовые файлы `dist/`.
6. `npx playwright install --with-deps chromium firefox webkit` — для E2E. В Linux установка системных браузерных библиотек может требовать администратора.
7. `npm run check` — типы, покрытие, сборка, E2E.

Для одной только передачи результата папку `node_modules` переносить не надо. Для долгосрочного воспроизведения храните исходники, lock-файл, версию Node/npm, готовый релиз, лицензии и SHA-256. `npm ci` требует доступности реестра; офлайн-сборка из исходников без заранее сохранённых пакетов не обещается.

## Обновление и откат

«Обновления» → «Проверить обновления» показывает наличие новой стабильной версии. Ничего не устанавливается автоматически. Экспортируйте нужную историю, скачайте новый HTML, проверьте сумму и откройте его. Старый файл можно оставить с номером версии; для отката откройте его. Неиспользуемые старые файлы удалите вручную. Online Pages после нового деплоя обновляется при перезагрузке вкладки.

## Удаление

1. Экспортируйте историю только если хотите её сохранить.
2. Нажмите «Завершить сеанс» → «Очистить сеанс»: обнуляются выражение, результат, история и настройки точности текущей вкладки.
3. Закройте **все** вкладки/окна Radical Lab.
4. Удалите `radical-lab.html` и его старые копии. При желании очистите корзину самостоятельно.
5. Удалите ненужные экспортированные `radical-lab-history.json` отдельно.
6. Для онлайн-версии при необходимости удалите данные/кэш соответствующего сайта через настройки браузера; удалите ярлыки, записи загрузок и сохранённые закладки по желанию.

Не остаются установленные службы, записи приложения в реестре, базы, service worker или локально сохранённые настройки: приложение их не создаёт. В памяти нет гарантии криптографического обнуления — JavaScript управляется сборщиком мусора. OS swap, browser session recovery, буфер обмена, кэши, резервные копии и облачная синхронизация могут сохранять следы; веб-приложение не имеет полномочий удалять их. Поэтому «без остатков компонентов приложения» и «100% криминалистическое стирание» — разные требования.

## Типичные проблемы

| Симптом | Решение |
| --- | --- |
| Пустая страница | Скачайте именно release asset, разрешите JavaScript, откройте поддерживаемым браузером |
| Ошибка вычислителя | Политика браузера могла запретить Blob Worker; попробуйте поддерживаемую конфигурацию |
| Текст вместо результата | Проверьте выражение; имена функций английские при любом языке GUI |
| Копирование запрещено | Выделите результат и скопируйте стандартным сочетанием клавиш |
| Нет обновлений / ошибка сети | Офлайн-расчёты доступны; проверьте Releases позже |
| Слишком длинный расчёт | Упростите выражение или уменьшите рабочую точность; отмена и тайм-аут сохраняют интерфейс |
