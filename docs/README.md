# Документация Radical Lab 1.0

Единый файл для чтения и сдачи: [Radical Lab проектная документация](Radical-Lab-Documentation.docx). Ниже сохранены текстовые исходники отдельных разделов для разработки и обновления документа.

| Документ                           | Для кого и зачем                                                        |
| ---------------------------------- | ----------------------------------------------------------------------- |
| [REQUIREMENTS.md](REQUIREMENTS.md) | Преподавателю/заказчику: границы системы и проверяемые требования       |
| [INSTALL.md](INSTALL.md)           | Пользователю: запуск, перенос, обновление и удаление                    |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Разработчику: компоненты, грамматика, арифметика, контракты             |
| [TESTING.md](TESTING.md)           | Тестировщику: стратегия, сценарии, покрытие и ограничения доказательств |
| [PROJECT_PLAN.md](PROJECT_PLAN.md) | Руководителю: роли, сроки, диаграмма Ганта, бюджет, риски               |
| [OPERATIONS.md](OPERATIONS.md)     | Сопровождению: релизы, обновления, деплой, откат и поддержка            |
| [DESIGN.md](DESIGN.md)             | Дизайнеру: визуальная система, состояния, доступность                   |
| [DEFENSE.md](DEFENSE.md)           | Студенту: сценарий демонстрации и пояснения к проектным решениям        |

Документы описывают реализованную версию отдельно от планов. Будущие мероприятия, учебный бюджет и назначение ролей не выдаются за реально выполненные работы или понесённые расходы.
